# NEXORA Rocket Arcade — demo starter

This is a responsive front-end prototype inspired by the supplied NEXORA screenshot.

## Included
- Neon blue NEXORA-style interface
- Rocket arcade button and points counter
- Referral, History, Leaderboard and Profile demo sections
- No Daily Bonus and no extra games

## Important
This is a local demo only. It does not connect to Telegram, a wallet, TON, a payment provider, or a real database. It uses points only; there are no wagers, deposits, cash-outs, or real-money withdrawals.

## Preview
Open `index.html` in a browser.

## Telegram Mini App deployment
To make this a Telegram Mini App, a developer will need to:
1. Host these files on an HTTPS website.
2. Create a bot using Telegram's official BotFather.
3. Configure the hosted HTTPS URL as the bot's Web App URL.
4. Add Telegram Web Apps SDK and a secure backend if Telegram user sign-in or persistent scores are needed.

Never share your bot token or wallet recovery phrase in chat.
